# WalkingPower

A public, single-page research guide to powered walking aids for an independently walking 80-year-old with knee osteoarthritis. It compares products available in Australia and Hong Kong, explains the limits of the evidence, and provides a practical trial checklist.

## Read the page

https://jfang88.github.io/WalkingPower/

The page is maintained in [index.html](index.html). Once GitHub Pages is enabled for the `main` branch and repository root, updates to this file appear at the URL above after publication.

## Edit the page

1. Open [index.html](index.html) and select the pencil icon (**Edit this file**).
2. Change the wording, prices, links, or date in the HTML.
3. Select **Commit changes**. GitHub keeps each version in the commit history.
4. Check the public page a few minutes later. Use a hard refresh if an older copy is cached.

The CSS is in the `<style>` section of the same file; no framework, build process, or API key is required. For larger edits, create a branch and pull request first.

## Maintain the research

Prices, stock, shipping, warranty and trial availability can change. Recheck the linked seller page and update the checked date whenever changing a product claim. Distinguish manufacturer claims from clinical studies: the cited studies do not establish that the retail products treat knee osteoarthritis.

## GitHub Pages setup

In **Settings → Pages → Build and deployment**, set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, then save. The repository must remain public for the simplest public reading experience.
